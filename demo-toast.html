MiaoYan Toast 样式方案对比

4 套方案 · 均使用项目设计系统 Token（--toast-* / --success-* / --warning-color / --shadow-*）· 覆盖成功 / 忙碌 / 警告三态

点击各方案按钮触发实时动效预览。「忙碌态」会先展示转圈进度，2.5 秒后自动转为成功态（模拟导入流程）。建议深浅两种主题各看一遍。

方案 A · 顶部胶囊 HUD 现样式精修
保持深色 HUD 与顶部居中，改为全胶囊造型 + 圆形图标徽标 + 弹性入场动效，比现在的方盒更精致。改动最小。
方案 B · 毛玻璃通知卡片 主题自适应
macOS 通知中心质感：浅色主题呈白磨砂、深色主题呈深磨砂，圆角方图标带语义底色，支持副标题（如扫描计数）。
方案 C · 底部极简 Pill 写作无扰
移至底部居中，小字号深色胶囊，自下而上轻弹。离视线焦点（正文区）更远，写作时存在感最低。
方案 D · 右下角通知卡片 桌面通知式
桌面应用常见位置，主副双行文案 + 自动消失进度条，信息量最大；适合导入这类长任务，日常保存提示略显厚重。
