# MiaoYan 版本变更（CHANGES）

> 按 TAG 版本记录用户可感知的新特性与重要变更（新→旧）。
> **同步约定**：执行「TAG 新版本」时，先为本文件补新版本条目并随 release commit 一并提交；
> GitHub Release 说明由 CI 自动提取本文件中「## 版本号（日期）」条目生成（无条目时回退 GitHub 自动生成）。
> 开发中若产生新机制/新坑，同步更新 `agent-development-guide.md`（§5 机制表 / §7 速查）与 `ai-dev-pitfalls.md`。
> 技术实现细节见 `agent-development-guide.md`；踩坑案例见 `ai-dev-pitfalls.md`。

## v1.0.44（2026-11-27）

- **修复阅读视图正文字体回退**：安全沙箱下的字体请求被资源协议跨源策略拒绝，正文一度回退系统字体；字体改为随预览页内联加载，仓耳今楷恢复正常显示

## v1.0.43（2026-11-27）

- **大库打开更快**：目录扫描复用缓存元数据，5 万文件笔记库的目录快照由约 18 秒降至 0.2 秒级（本机基准）
- **保存更可靠**：笔记写入改为原子落盘 + 磁盘版本校验 + 持久化日记账；保存失败保留草稿并显示恢复横幅，异常中断后可恢复未保存内容
- **切换笔记库不再串数据**：A→B→A 切换时旧库扫描会被取消并隔离，不再覆盖或混入当前库
- **移除外部文件夹更安全**：嵌套 / 别名根移除前校验覆盖范围，不会误删仍被主库覆盖的笔记；不相交的移除不再触发全库重扫
- **搜索更快更稳**：大文件改为流式搜索（64MiB 约 19ms、内存增量约 128KiB）；连续输入或切库时旧搜索自动失效，结果不再串档
- **批注外部修改保护**：批注文件被外部改动时保存提示冲突并保留外部内容，重试自动基于最新版本写入，不再静默覆盖
- **设置只在保存成功后生效**：笔记库路径在配置写入成功后才会切换；欢迎页选择目录失败会显示错误并可重试
- **五语言补齐**：繁体中文 / 日文 / 西班牙文补齐工具栏目录、演示、调试日志、复制文件名等缺失文案，并加入键集一致性检查
- **关于页更新检查更稳**：检查请求增加超时兜底；更新方式保持手动检查 + 跳转下载

## v1.0.42（2026-11-05）

- **修复目录树频繁整块刷新**：任意文件的新增/删除/改名只更新对应行，不再触发整个父级目录重扫；大库（7000+ 笔记）不再出现每次 4–6 秒的全量扫描
- **外部改动更平滑**：修改笔记只原位更新该行、不重排父目录；外部新建/改名/删除文件夹也会增量更新目录树，展开状态不丢失
- **修复扫描期间的新改动被回滚**：启动扫描进行中新建的笔记/文件夹，不会再被晚到的扫描结果覆盖消失

## v1.0.41（2026-10-20）

- **修复 Windows 下笔记库子文件夹无法重命名/删除**：文件监听改为每个根目录一条递归监听，不再为每个子目录持有句柄；资源管理器中整理文件夹不再报“需要权限”

## v1.0.40（2026-10-09）

- **文件树即时更新**：新建文件、重命名、拖拽移动后侧栏本地插行/换行，不再全量刷新——展开的文件夹不再收起又展开

## v1.0.39（2026-10-08）

- **设置新增「关于」标签页**：显示当前版本，自动检查 GitHub 最新 release，发现新版一键跳转下载；附仓库入口
- **Release 说明规范化**：打 TAG 发布时，CI 自动提取本文件对应版本条目作为 GitHub Release 说明，不再显示占位文案

## v1.0.38（2026-09-24）

- **修复重命名闪现双标题**：重命名/移动笔记时文件列表本地即时换行，不再短暂同时显示新旧两个标题

## v1.0.37（2026-09-24）

- **修复重命名后旧文件名重现**：重命名/移动后正确更新已打开标签页路径，「未命名」旧文件名不再回弹
- **CI 自动发布正式版**：各平台构建全部成功后自动将 Draft Release 转为正式发布

## v1.0.36（2026-09-08）

- **右键菜单体验优化**：文件夹菜单「复制文件夹路径」移至「在终端中打开」下方，不再与「复制文件夹名称」相邻误触
- **菜单不再飘出窗口**：所有右键菜单贴近窗口右/下边缘时自动收回视口内，完整可见

## v1.0.35（2026-08-31）

- **右键菜单支持复制路径**：文件右键「复制文件路径」、文件夹右键「复制文件夹路径」、TAB 右键「复制路径」，五种语言齐备

## v1.0.34（2026-08-30）

- **Toast 全新样式**：毛玻璃通知卡片（macOS 通知中心质感），浅/深主题自动适配白磨砂/深磨砂表面
- **语义化图标**：成功绿色勾、警告橙色叹号、进行中 accent 转圈，圆角方底色徽标；「不支持的文件格式」等警告不再误显示成功绿点

## v1.0.33（2026-08-30）

- **外部文件夹增量导入**：双击/拖入外部 .md 只扫新目录、秒级完成，不再触发全库重扫
- **外部文件夹增量移除**：点 ✕ 后文件夹行与总数同帧消失，零全扫；在途扫描结果不再「复活」已移除行
- **Toast 样式对齐设计系统**：深色半透明 HUD（明暗主题一致），普通态成功绿点、忙碌态白色 spinner

## v1.0.32（2026-08-30）

- **导入进度 Toast**：导入外部文件夹时 Toast 实时显示已扫描文件数
- **日志迁移**：运行日志迁至 `~/.miaoyan/log`
