# MiaoYan 版本变更（CHANGES）

> 按 TAG 版本记录用户可感知的新特性与重要变更（新→旧）。
> **同步约定**：执行「TAG 新版本」时，先为本文件补新版本条目并随 release commit 一并提交；
> 开发中若产生新机制/新坑，同步更新 `agent-development-guide.md`（§5 机制表 / §7 速查）与 `ai-dev-pitfalls.md`。
> 技术实现细节见 `agent-development-guide.md`；踩坑案例见 `ai-dev-pitfalls.md`。

---

## v1.0.35（2026-08-31）

- **右键菜单支持复制路径**：文件右键「复制文件路径」、文件夹右键「复制文件夹路径」、TAB 右键「复制路径」，五种语言齐备

## v1.0.34（2026-08-30）

- **Toast 全新样式**：毛玻璃通知卡片（macOS 通知中心质感），浅/深主题自动适配白磨砂/深磨砂表面
- **语义化图标**：成功绿色勾、警告橙色叹号、进行中 accent 转圈，圆角方底色徽标；「不支持的文件格式」等警告不再误显示成功绿点

## v1.0.33（2026-08-30）

- **外部文件夹增量导入**：双击/拖入外部 .md 只扫新目录、秒级完成，不再触发全库重扫
- **外部文件夹增量移除**：点 ✕ 后文件夹行与总数同帧消失，零全扫；在途扫描结果不再「复活」已移除行
- **Toast 样式对齐设计系统**：深色半透明 HUD（明暗主题一致），普通态成功绿点、忙碌态白色 spinner

## v1.0.32（2026-08-30）

- **渐进加载**：目录树逐目录分块渲染，首屏不再等全库扫完；扫描期总数以分数（已加载/总数）显示
- **导入进度 Toast**：导入外部文件夹时 Toast 实时显示已扫描文件数
- **日志迁移**：运行日志迁至 `~/.miaoyan/log`

## v1.0.31（2026-08-28）

- **注册为 .md 默认编辑器**：双击 .md 文件或右键「使用 Miaoyan 打开」直接打开（单实例转发），设置内可开关

## v1.0.30（2026-08-26）

- **批注系统升级**：批注面板改为右侧固定侧边栏（挤压式、非遮挡式）
- **操作按钮常显**：批注卡片 编辑/已解决/删除 按钮常显，不再被长标题挤出可视区

## v1.0.29（2026-08-24）

- **深度性能优化大包**：重型库（mermaid/markmap/katex 等）按需加载、字体子集化（18MB→0.43MB）、Vendor 分包、预览渲染防抖、zustand 窄订阅

## v1.0.28 及更早

见仓库 git tag 历史（`gh api repos/MLeft/Miaoyan-tauri/tags`）。
